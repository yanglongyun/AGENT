# 0.0.4 — 图片与文件

这一版为 Web 对话补齐图片和普通文件发送，并让 `read` 工具能够把本地图片交给模型查看。

## 数据链路

- 浏览器支持选择、拖拽图片和文件，发送前展示附件并允许移除。
- 上传内容按 SHA-256 存入 `.data/files`；消息与 SQLite 只保存名称、路径、类型、大小等元数据，不保存 Base64。
- 请求 Responses API 时，当前用户消息中的图片才临时展开成 `input_image`；普通文件作为可读取的本地路径交给 Agent。
- `read` 遇到 PNG、JPEG、GIF、WebP 时返回图片描述；工具结果在当前轮请求模型前沿用相同的 `input_image` 通道。
- 旧轮次不会反复携带图片字节；当前轮最多携带多少张工具图片、单文件大小及每条消息附件数均由配置控制。

## 配置

见 `config.example.js` 的 `images`：

- `maxBytes`：单文件上限。
- `maxPerMessage`：每条消息附件上限。
- `maxLiveToolImages`：单轮保留给模型看的工具图片数。
- `directory`：受管文件目录。

本版没有引入权限系统；上传、模型输入与工具执行仍保持为彼此清晰的模块边界。
