# 0.1.7 — 提议作为待确认的编辑

规则提议从仅追加改为 old_text → new_text 的精确替换，复用 edit 工具的文本替换逻辑，支持新增、修改、删除和 replace_all。

- 详情弹窗展示修改前后；点击同意才更新本对话规则。
- 创建提议和同意时均校验原文。原文不存在、匹配不唯一或空白规则已被填写时，拒绝应用并提示冲突；确认失败后仍保留待处理提议。
- 只替换匹配片段，保留其他位置后来增加的规则；保留 CRLF 行尾，替换内容中的美元符号按原文处理。
- 新增时可替换包含原文的片段；仅当前规则为空时允许空 old_text。new_text 为空表示删除。
- 旧版待处理追加提议保留原有含义；后续问题提议仍填入草稿，不自动发送。

验证：63 项测试、JavaScript 语法检查和前端生产构建通过。无需新增数据库字段。
