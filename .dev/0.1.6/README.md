# 0.1.6 — 对话规则、应用任务与初始应用

## 对话与任务

聊天保存在 chats，任务保存在 tasks；任务只由应用创建。两者通过 thread 共用 messages 和 compactions。移除工作目录设置，统一在 AGENT 根目录执行。工具 bash 更名为 shell。

规则以整段文本保存在 chats.rules。标题栏右侧面板编辑全局提示词和本对话规则，每次请求组合读取。大屏面板与对话并排，小屏使用遮罩，显示隐藏无动画。

propose 异步展示在输入框上方，提供同意、忽略与详情弹窗。规则提议同意后追加到当前对话规则；问题提议填入草稿，不自动发送。待处理提议随消息持久化。

## 初始应用与界面

内置笔记、创意和思维导图三个应用。应用顶部操作收进更多菜单，对话入口打开侧栏；点击标题切换历史。底部任务入口查看所有应用任务及执行详情。

导图支持生成子节点、调整同级顺序、拖动排序及移动节点；编辑框随内容扩展，手机长按打开节点菜单，工具栏空间不足时只显示图标。

回答完成后原地收尾，不再拉取历史替换消息列表；最终正文通过事件校准，保留消息节点及已加载的历史。

## 数据迁移与运行

首次迁移旧 conversations 数据库时生成 .backup，保留聊天、消息和模型摘要，移除旧逐条规则及提议表；旧规则可从备份恢复。现有 chats 数据库自动补充 rules 字段，默认空文本。

压缩只允许模型摘要，失败直接报错并保留历史，不再机械裁剪。

启动：npm start。界面开发：npm run dev。生产构建：npm run build。

## 验证

npm test、npm run check、npm run build。包含任务、接口、迁移、初始应用、异步提议与流式收尾回归测试。
